# PixelEditor
This pixel editor is crucial for creating art for my custom handheld console project. It allows me to make and export art for a start screen, menu, score, etc.

Steps for getting your art / an image to show on the Handheld Console Screen:

1. Visit the GitHub Pages for this repo.

2. Create your design (helpful tools are at the bottom of the page - erase, color selection, etc.)

3. Click "Export to Arduino Code", it will prompt you for a name for your file. This file contains an array of the pixels and their colors which you will use to display.

4. Transfer that file over into the same folder as the rest of the Handheld Console sofware.

5. Import that file in menu.ino (the main file). Display that image on the Console by using the data stored (in the array).
